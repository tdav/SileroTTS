# TtsTray — чтение текста вслух голосами Silero и Microsoft

Небольшая программа для Windows, которая живёт в трее и читает текст вслух голосами SAPI:
качественными нейросетевыми голосами **Silero** и стандартными голосами **Microsoft**.

Главный сценарий — **скопировал длинный текст, и он сам зазвучал**, без переключения окон.
Второй — вставить или набрать текст в окне программы и нажать «Озвучить».

Написана только на C# (.NET 10, WinForms). Python, PyTorch и ONNX не нужны: голоса Silero
подключаются через установленный движок Silero TTS SAPI.

---

## Возможности

- **Работа из трея.** После запуска окно не показывается, программа сразу сворачивается в трей.
  Двойной клик по иконке — открыть окно, крестик — снова спрятать в трей.
- **Автоозвучка буфера обмена.** Если скопирован текст, в котором слов **больше порога**
  (по умолчанию 100, настраивается), он читается автоматически. Окно при этом не всплывает
  и фокус не забирается; читаемый текст появляется в поле ввода программы.
  - Новый длинный текст прерывает текущее чтение.
  - Повторные уведомления на одно копирование (браузеры и Office присылают их несколько) не перезапускают чтение.
  - Короткие копирования (пароли, ссылки, отдельные слова), файлы и картинки игнорируются.
- **Окно с полем ввода** и кнопками «Озвучить», «Пауза/Продолжить», «Стоп», «Настройки…».
  `Ctrl+Enter` в поле — то же, что «Озвучить».
- **Глобальные горячие клавиши** (работают из любой программы):

  | Сочетание | Действие |
  |---|---|
  | `Ctrl+Alt+P` | пауза / продолжить |
  | `Ctrl+Alt+S` | стоп |

- **Два «движка» в одном списке голосов** — Silero и Microsoft, сгруппированные в окне настроек.
- **Настройки:** голос (с кнопкой «Прослушать»), скорость, громкость, порог слов,
  включение автоозвучки, автозапуск вместе с Windows, кнопка «Настройки Silero…»
  (ударения и омографы настраиваются утилитой Silero).
- **Иконка в трее** меняет цвет: синяя — покой, зелёная — идёт чтение.
- Один экземпляр: повторный запуск открывает окно уже работающей программы.

## Что нужно установить

| Что | Зачем | Где взять |
|---|---|---|
| Windows 10 / 11, **x64** | программа собрана только под x64 — движок Silero 64-битный | — |
| **Silero TTS SAPI** (проверено на версии 1.0.2) | голоса Silero для SAPI | [github.com/snakers4/silero-models/releases](https://github.com/snakers4/silero-models/releases) — файл `SileroTTS_Setup_*.exe` (или `SileroTTS_Ru_Setup_*.exe` только с русской моделью) |
| **.NET 10 Desktop Runtime** (x64) | запуск программы | [dotnet.microsoft.com/download/dotnet/10.0](https://dotnet.microsoft.com/download/dotnet/10.0) |
| **.NET 10 SDK** | только для сборки из исходников | там же |

Голоса Microsoft (Irina, David, Zira) входят в Windows. Без Silero программа тоже работает — только с ними.

Проверить, что голоса Silero установились (PowerShell):

```powershell
(New-Object -ComObject SAPI.SpVoice).GetVoices() | ForEach-Object { $_.GetDescription() }
```

В списке должны появиться голоса вида `Aigul (Russian)`, `Zinaida (Russian)` и т. п.

## Сборка и запуск

Запуск из исходников:

```bash
dotnet run --project src/TtsTray
```

Сборка готовой программы в папку `publish`:

```bash
dotnet publish src/TtsTray/TtsTray.csproj -c Release -r win-x64 --self-contained false -o publish
```

После этого запускается `publish\TtsTray.exe`. Папку можно перенести в любое место
(например, `C:\Program Files\TtsTray`) — настройки хранятся отдельно, в профиле пользователя.

## Как пользоваться

1. Запустите `TtsTray.exe`. Окна не будет — в трее появится синяя иконка с динамиком.
   Первые несколько секунд подсказка иконки — «загрузка голоса…»: модель Silero загружается в фоне,
   чтобы первое чтение не ждало.
2. **Скопируйте длинный текст** (больше 100 слов) в любой программе — он начнёт читаться.
   Иконка станет зелёной.
3. Управление чтением: `Ctrl+Alt+P` — пауза/продолжить, `Ctrl+Alt+S` — стоп.
   То же есть в меню иконки (правый клик) и кнопками в окне.
4. Чтобы прочитать свой текст — двойной клик по иконке, вставьте текст в поле, нажмите «Озвучить»
   (или `Ctrl+Enter`).
5. **Настройки** — правый клик по иконке → «Настройки…»:
   - выберите голос в списке и нажмите «Прослушать»;
   - отрегулируйте скорость и громкость;
   - задайте порог «если в нём слов больше» или выключите автоозвучку буфера;
   - при желании включите «Запускать вместе с Windows»;
   - «Сохранить» применяет настройки, «Отмена» возвращает прежние.
6. Выход — правый клик по иконке → «Выход». Крестик окна программу **не** закрывает, а прячет в трей.

### Где хранятся настройки

- Файл настроек: `%APPDATA%\TtsTray\settings.json`. Если он испорчен, программа стартует с настройками по умолчанию.
- Автозапуск: значение `TtsTray` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

## Решение проблем

| Симптом | Причина и что делать |
|---|---|
| Нет голосов Silero в списке | Не установлен Silero TTS SAPI, или программа запущена как 32-битная. Установите Silero; используйте сборку x64. |
| «Сохранённый голос не найден» при запуске | Голос удалён (например, переустановили Silero). Выбран голос по умолчанию; выберите нужный в настройках и сохраните. |
| «Сочетание … занято другой программой» | Другая программа уже использует `Ctrl+Alt+P` или `Ctrl+Alt+S`. Работают меню трея и кнопки окна. |
| Первое чтение после запуска начинается с задержкой | Silero загружает модель (3–9 с). Программа прогревает голос в фоне сразу после старта. |
| Читаются вслух теги или код | Скопирован HTML/XML/код длиннее порога. Поднимите порог или выключите автоозвучку. |

## Что сделано

- Спецификация: [`docs/superpowers/specs/2026-10-19-tts-tray-design.md`](docs/superpowers/specs/2026-10-19-tts-tray-design.md)
- План реализации: [`docs/superpowers/plans/2026-10-19-tts-tray.md`](docs/superpowers/plans/2026-10-19-tts-tray.md)

Реализовано по плану из трёх задач (каркас и трей → автоозвучка буфера → окно настроек),
затем — исправления по независимому ревью кода и доработки (горячие клавиши, иконки, показ текста в поле ввода).
Автотестов нет — по решению автора; проверка — сборка и ручная приёмка из спецификации.

### Структура проекта

```
TtsTray.slnx
src/TtsTray/
  Program.cs              — точка входа: один экземпляр, скрытый старт, цикл сообщений без главной формы
  SapiSpeaker.cs          — обёртка над COM SAPI.SpVoice: голоса, чтение, пауза, стоп, прогрев
  MainForm.cs             — окно, иконка в трее, буфер обмена, горячие клавиши
  SettingsForm.cs         — окно настроек
  AppSettings.cs          — настройки в JSON
  Resources/app.ico       — иконка программы (покой)
  Resources/reading.ico   — иконка трея во время чтения
docs/superpowers/         — спецификация и план
```

### Технические особенности (важно при доработке)

- **SAPI — только через COM `SAPI.SpVoice`** (`Type.GetTypeFromProgID` + `dynamic`).
  `System.Speech.Synthesis.SpeechSynthesizer` голоса Silero видит, но выдаёт **тишину**.
- **Один экземпляр `SpVoice`** на всё время работы: создание нового стоит ~1,4 с, первая загрузка Silero — 3–9 с.
- **Ловушка паузы SAPI:** если остановить чтение на паузе, голос *остаётся* на паузе, и следующее чтение молчит
  до `Resume()`. Пауза — счётчик: два `Pause()` требуют двух `Resume()`. Всё это учтено в `SapiSpeaker`.
- **Ограничение движка Silero:** он делит текст на предложения **только по точке**. Одно «предложение» длиннее
  ~900 символов даёт ошибку, а ~3000 символов роняет весь процесс внутри `silero_tts_sapi.dll` или подвешивает его.
  Поэтому перед чтением строки без знака в конце получают точку, а участки длиннее 400 символов режутся точкой.
- Текст передаётся с флагом `SVSFIsNotXML`: иначе текст, начинающийся с `<`, разбирается как SAPI XML.
- Окончание чтения определяется опросом `WaitUntilDone(0)`; `Status.RunningState` ненадёжен.
- Все обращения к `SpVoice` и буферу обмена — только из UI-потока (STA).

### Известные ограничения

- Сочетания клавиш фиксированы (`Ctrl+Alt+P`, `Ctrl+Alt+S`), в настройках не меняются.
- Нет сохранения в WAV/MP3, SSML, подсветки читаемого слова, установщика.
- Если вручную вписать в `settings.json` порог больше 100000, окно настроек не откроется — исправьте значение в файле.
- При повторном запуске окно уже работающей программы может лишь мигнуть на панели задач, а не выйти на передний план.
